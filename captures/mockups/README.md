# Composed mockups

`compose-sessions-panel.py` draws the proposed Sessions widget and panel from `spec/03-sessions-panel.md` over two real rig screenshots from the Phase 1 baseline (the empty desktop and the crash-notification frame). Output files carry `proposed` in their names and a stamp in the corner. Fonts are DejaVu, so type will differ from the shell's; geometry, color roles, hierarchy, and copy are what the composites carry. Rerun: `python3 compose-sessions-panel.py` from a directory holding `baseline/` PNGs.
